About

I build AI applications from first design to working software.

My platform work covers enterprise chatbots with tool calling and custom functions, multi-agent systems, MCP integrations and multimodal features such as speech, vision and image generation, all on Azure OpenAI and Azure AI Foundry.

My day job is on the production side. At Tech Mahindra I support backend services and web applications for the Microsoft Xbox ecosystem: tracing root causes through logs, APIs and databases, validating fixes with Postman and SQL, and writing Python automation.
